Device Owner

Optional, on a phone dedicated to the agent.

The agent then turns on Android’s security log and network log. It sets no other policy. This needs a factory-reset phone with no Google or other accounts added.

01

Set the owner with adb

Install the app on the freshly reset phone, then:

adb shell dpm set-device-owner com.wazuh_mobile_client.android/io.github.hannescoetzee.wazuhagent.admin.AgentDeviceAdminReceiver

Open the app and enroll as usual. The Capabilities card shows whether the security and network logs are on.

02

What those logs contain

  1. Security log

    ADB shell commands, interactive shells, files pulled or pushed over ADB, CA certificate installs and removals, logging stopped, key integrity violations, wipe failures, a full log buffer, cryptographic self-test failures, and external storage mounts.

  2. Network log

    DNS lookups and connections, grouped per app and destination in each batch.

Android delivers both logs in batches, often an hour or more apart, so these events arrive late.

03

QR provisioning

A factory-reset phone can be set up from a QR code instead of adb. The phone downloads the app, makes it Device Owner, and enrolls with the manager without anyone typing the settings.

  1. Use the release APK

    PROVISIONING_DEVICE_ADMIN_PACKAGE_DOWNLOAD_LOCATION is the latest release. The phone downloads it during setup. You do not host the file yourself. The example payload already has this URL:

    https://github.com/skuilplek/wazuh-android-agent/releases/latest/download/wazuh-agent-release.apk

  2. Fill the payload

    Copy provisioning/qr_payload.example.json. Leave PROVISIONING_DEVICE_ADMIN_PACKAGE_DOWNLOAD_LOCATION as the URL above.

    PROVISIONING_DEVICE_ADMIN_SIGNATURE_CHECKSUM is the signing certificate of the APK the phone downloads, not of a build on your computer. Download wazuh-agent-release.apk from that URL, then run:

    curl -fsSL -o wazuh-agent-release.apk \
  https://github.com/skuilplek/wazuh-android-agent/releases/latest/download/wazuh-agent-release.apk
apksigner verify --print-certs wazuh-agent-release.apk | grep 'SHA-256' | head -1 | awk '{print $NF}' \
  | xxd -r -p | base64 | tr '+/' '-_' | tr -d '='

    Paste the result into the payload. The checksum stays valid for later releases only while they are signed with the same key.

    Admin extras: manager_host, enroll_port, agent_port, enrollment_password, groups, and optionally agent_name and keepalive_seconds.

    manager_cert_sha256 is the SHA-256 of the manager’s authd certificate, so the first enrollment is pinned instead of trusting whatever certificate it sees. Remove the key to trust the first certificate instead.

    openssl x509 -in /var/ossec/etc/sslmanager.cert -noout -fingerprint -sha256

  3. Make the code

    qrencode -o payload.png < payload.json

  4. Scan it

    On the phone’s welcome screen, tap six times to open the QR reader and scan the code.

If enrollment fails during setup, for example because the manager is not reachable yet, the settings are kept and you can tap Enroll in the app later.

04

Remove it

To remove Device Owner, factory-reset the phone.
