Install

Download the app and enroll the phone.

The latest release APK sideloads without a build. JDK 17 and the Android SDK are only needed if you build it yourself.

01

Download

This is the latest release APK. The address stays the same when a new version is published.

Download wazuh-agent-release.apk

02

Put it on the phone

  1. Open the APK

    On the phone, download wazuh-agent-release.apk or copy it across, then open it. When Android asks, allow installs from the browser or the Files app.

  2. Or install over USB

    Enable Developer options, then USB debugging, and connect the phone. The file below is the APK you downloaded.

    adb install -r wazuh-agent-release.apk

  3. Enroll

    Open Wazuh Agent. It opens on the Settings tab until the phone is enrolled. Enter the manager address, add the enrollment password if the manager uses one, then tap Enroll.

    Enrollment fails with Invalid group if a group you enter does not exist. Create the group on the manager first.

  4. Let it keep running

    Allow the notification, and allow the app to run unrestricted in the background so Android does not kill the connection. While the agent is running it holds a wake lock so the session stays up with the screen off. Run unrestricted in background is still required on phones that kill foreground services anyway.

    On Android 12, also allow Alarms and reminders if the Status tab asks, so the agent can restart itself. The Status tab lists anything still missing under Needs attention.

  5. Failed unlocks, if you want them

    Tap Allow next to Device admin. The admin only uses the watch-login policy: it cannot lock, wipe, or change the phone. If it is turned off later, the manager gets an alert (rule 100265).

    Once enrolled, you can turn USB debugging off again. The agent reports it as a posture finding while it is on.

03

Requirements

Skip this and the next section if you installed the release APK. Building from source needs JDK 17 and Android SDK platform 35. These commands assume Homebrew on macOS. Point JAVA_HOME and ANDROID_HOME at the same places if you install the JDK and SDK another way.

brew install openjdk@17
brew install --cask android-commandlinetools
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
echo "sdk.dir=$ANDROID_HOME" > local.properties

04

Build

Protocol tests use vectors built independently from the Wazuh C sources. ./build_app.sh rebuilds the debug APK into app/build/outputs/apk/debug/.

./gradlew :protocol:test
./build_app.sh

Install that build with adb install -r app/build/outputs/apk/debug/wazuh-agent-*-debug.apk.

05

Certificate and versions

The app pins the manager’s enrollment certificate the first time it enrolls. Later enrollments to the same host must present the same certificate.

  1. App version

    1.0.0 (version code 1), from versionName and versionCode. It is shown in the app, sent in every event as android.app_version, and sent as the agent label agent.app_version. Bump it for each build you install.

  2. Protocol version

    Negotiated at enrollment. The app picks the newest version the manager accepts, because Wazuh rejects agents that are newer than the manager.

To enroll a throwaway agent against a real manager, set the address and password and run the live test. The host below is an example.

WAZUH_MANAGER=192.168.1.10 WAZUH_PASSWORD=secret ./gradlew :protocol:test --tests '*LiveManagerTest*'
